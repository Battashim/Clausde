# Pitchcraft Coaching Lab

A single-page interactive coaching guide (open `index.html` in a browser):

- **License path**: US Soccer D → C → B → A → Pro. What each course assesses, what to study, how to pass, and a checklist saved in your browser.
- **The method**: Coerver pyramid + Ekkono game-intelligence principles, plus the 4 Pitchcraft rules, Play–Practice–Play and the 4 moments.
- **Drill library**: 17 original animated drills, filterable by position (DEF / MID / ATT / GK) and skill.
- **Fix a problem**: game problem → cause → what to coach → drills.
- **Session builder**: generates a timed Play–Practice–Play session.

Requirements change. Confirm current prerequisites at https://learning.ussoccer.com.
